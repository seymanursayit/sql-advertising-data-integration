# SQL Advertising Data Integration

## Overview
This project combines Facebook Ads and Google Ads data using SQL, Common Table Expressions (CTEs), and UNION ALL.

## Objectives
- Combine advertising data from multiple sources
- Aggregate daily advertising metrics by date and media source
- Calculate total spend, impressions, clicks, and conversion value

## SQL Concepts
- Common Table Expressions (CTEs)
- UNION ALL
- Aggregate functions (SUM)
- GROUP BY and ORDER BY

## Tools
- PostgreSQL
- SQL

## File
- `union-cte-advertising-analysis.sql` — SQL query for combining and aggregating advertising data.
